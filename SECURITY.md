# Security

Cleaner moves files, asks for the administrator password for system items and installs a privileged helper. A bug in any of these can cost someone their data, so please report it privately.

**How:** open a [private security advisory](https://github.com/ciro-maciel/cleaner/security/advisories/new) on this repository. Please don't open a public issue for it.

**What helps:** the macOS version, the steps, what was moved or exposed, and whether the quarantine still holds it.

You will get an answer within a week. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.

Supported: the latest release only.
